## How These Documents Relate

```
                    EXECUTIVE-BRIEF.md
                    "Should we invest?"
                          │
                          ▼
                 ENGINEERING-MANAGER.md
                 "How do we adopt?"
                    │           │
                    ▼           ▼
            ARCHITECT.md    QUICK-START.md / USER-GUIDE.md
            "How does it     "How do I use it?"
             fit our
             architecture?"
```

**Top-down flow:** Executive reads the brief, hands it to their engineering manager. Manager follows the adoption playbook and assigns a developer to pilot. Architect evaluates how it fits into existing governance.

**Bottom-up flow:** Developer discovers Synthesis, installs it, sees value, shares the Manager Guide with their lead, who shares the Executive Brief upward.
