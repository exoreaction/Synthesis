## Usage Guidelines

### For Sales & Marketing

**LinkedIn Posts:**
- Use infographics as post images
- Extract key metrics (92-95% reduction, 10-12x faster) as quote graphics
- Link to docs/perspectives/ guides for deep dives

**Sales Decks:**
- Start with chaos-to-clarity or executive-ai-paradox (problem framing)
- Use synthesis-overview as solution slide
- End with workshop or product-manager visuals (depending on audience)

**Email Campaigns:**
- Attach relevant infographic based on recipient role:
  - Executives → executive-ai-paradox.png
  - PMs → product-manager-knowledge-center.png
  - Developers → synthesis-overview-infographic.png

### For Workshops

**Pre-Workshop Marketing:**
- Use workshop-mastering-ai-output.png in email invites
- Share on LinkedIn with registration link

**Workshop Opening:**
- Use slides from managing-ai-output-presentation.pdf for problem framing
- Transition to live demo after problem is established

**Post-Workshop Follow-Up:**
- Include synthesis-overview-infographic.png as quick reference
- Attach developer-infrastructure-presentation.pdf for continued learning

### For Documentation

**Website:**
- Use synthesis-overview as hero image on homepage
- Use chaos-to-clarity on "Why Synthesis?" page
- Use role-specific infographics on perspective pages

**GitHub README:**
- Embed synthesis-overview-infographic.png at top of README
- Link to visuals/ directory from documentation sections

**Blog Posts:**
- Extract individual slide images from PDFs
- Use infographics as featured images
